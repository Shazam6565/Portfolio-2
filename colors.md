## 🎨 Color Reference

Monochrome only — black ink on white paper. No accent colors.

| Token          | Hex       | Usage                             |
| -------------- | --------- | --------------------------------- |
| Background     | `#ffffff` | Page background, everywhere       |
| Surface        | `#f6f6f6` | Code blocks, chips, table stripes |
| Line           | `#e6e6e6` | Hairline borders and dividers     |
| Text           | `#111111` | Headings, links, emphasis         |
| Text secondary | `#4d4d4d` | Body text                         |
| Text muted     | `#8a8a8a` | Dates, labels, tech tags          |
| Accent         | `#000000` | Hover / active states             |
